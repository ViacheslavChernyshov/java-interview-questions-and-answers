# What Does anyOf() Method Do and When is It Useful?

---

## 🟢 Junior Level

**`CompletableFuture.anyOf()`** is a static combinator method used to race an arbitrary number ($N$) of independent asynchronous futures. It completes as soon as the **first future completes** (either successfully or with an exception):

```
  Taxi Hail Analogy:
  • You call 3 different taxi apps (Uber, Lyft, Bolt) simultaneously.
  • As soon as the **first** driver arrives at your door (`anyOf`), you hop in and start your trip, 
    ignoring whichever apps were slower!
```

```java
CompletableFuture<String> fastServer = CompletableFuture.supplyAsync(() -> {
    sleep(100);
    return "Fast Replica Response";
});

CompletableFuture<String> slowServer = CompletableFuture.supplyAsync(() -> {
    sleep(1000);
    return "Slow Replica Response";
});

// Completes in ~100ms with the fastest response:
CompletableFuture<Object> fastest = CompletableFuture.anyOf(fastServer, slowServer);

fastest.thenAccept(result -> System.out.println("Fastest result: " + result)); // "Fast Replica Response"
```

### Type Safety & Casting Nuance

Because `anyOf()` can accept futures with different generic types (`CF<String>`, `CF<Integer>`), it returns **`CompletableFuture<Object>`**:

```java
// Type-safe extraction using Java 16+ Pattern Matching:
CompletableFuture.anyOf(fetchStringAsync(), fetchIntegerAsync())
    .thenAccept(obj -> {
        if (obj instanceof String s) {
            log.info("Received String payload: {}", s);
        } else if (obj instanceof Integer i) {
            log.info("Received Integer code: {}", i);
        }
    });
```

## 🔴 Senior Level

### The Slower Future Leak (Zombie Tasks Hazard)

> [!WARNING]
> **`anyOf()` DOES NOT cancel the other slower running futures!**
> When the fastest future finishes, the remaining $N - 1$ futures **continue executing in the background**, consuming CPU, memory, and database connections!

```
  [fastServer: Completes in 100ms] ──► `anyOf` triggers downstream callback!
  [slowServer: Still running!]     ──► Continues executing for 5,000ms in background (WASTED RESOURCES!)
```

#### Senior Solution: Explicit Cancellation of Stragglers

```java
public static <T> CompletableFuture<T> raceWithCancellation(List<CompletableFuture<T>> futures) {
    CompletableFuture<Object> anyDone = CompletableFuture.anyOf(futures.toArray(new CompletableFuture[0]));

    // When the first future wins, cancel all other remaining futures:
    anyDone.whenComplete((result, ex) -> {
        for (CompletableFuture<T> f : futures) {
            if (!f.isDone()) {
                f.cancel(true); // 🛡️ Cancel slower stragglers to save system resources!
            }
        }
    });

    @SuppressWarnings("unchecked")
    CompletableFuture<T> typedResult = (CompletableFuture<T>) anyDone;
    return typedResult;
}
```

## 🎯 Interview Cheat Sheet

**Must Know:**
- **Purpose:** Races $N$ futures; completes as soon as the **first future finishes** (success or failure).
- **Return Type:** Returns `CompletableFuture<Object>`; requires casting or pattern matching.
- **Top Pattern:** **Hedged Requests** (querying multiple replicas to cut p99 tail-latency).
- **Resource Hazard:** Does **NOT** cancel slower tasks; stragglers run to completion unless explicitly cancelled with `.cancel(true)`.

**Common Follow-up Questions:**
- *"What happens if the first future throws an exception?"* → `anyOf()` fails immediately with that exception (Fast-Fail), even if another future might have completed successfully a few milliseconds later.
- *"How is `anyOf()` implemented internally?"* → Uses an internal `OrRelay` completion node registered across all source futures. The first future to push its result triggers `OrRelay.completeRelay()`, ignoring subsequent pushes.
- *"What is the difference between `anyOf()` and `acceptEither()`?"* → `acceptEither` races exactly 2 futures and takes a `Consumer<T>`; `anyOf` races $N$ futures and returns `CompletableFuture<Object>`.

**Red Flags (DO NOT Say):**
- ❌ *"anyOf() automatically cancels and interrupts the other slower futures."* (It does NOT cancel slower tasks; you must cancel them manually).
- ❌ *"anyOf() waits until at least one future succeeds without errors."* (`anyOf` completes on the first event—if the first future fails, `anyOf` fails instantly).
- ❌ *"anyOf() returns a typed `CompletableFuture<T>`."* (It returns `CompletableFuture<Object>` to accommodate heterogeneous futures).
