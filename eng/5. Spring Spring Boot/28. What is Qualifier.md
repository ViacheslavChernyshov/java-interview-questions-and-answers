# What is Qualifier?

---

## 🟢 Junior Level

**`@Qualifier`** is an annotation used to **disambiguate and select a specific bean** when multiple candidate beans of the same type or interface are registered in the Spring IoC container.

```java
@Configuration
public class NotificationConfig {

    @Bean @Qualifier("smsSender")
    public MessageSender smsSender() { return new SmsSender(); }

    @Bean @Qualifier("emailSender")
    public MessageSender emailSender() { return new EmailSender(); }
}
```

```java
@Service
public class AlertService {
    private final MessageSender messageSender;

    // Explicitly chooses the `smsSender` bean:
    public AlertService(@Qualifier("smsSender") MessageSender messageSender) {
        this.messageSender = messageSender;
    }
}
```

---

## 🟡 Middle Level

### The `@Qualifier` vs. `@Primary` Rule

> [!IMPORTANT]
> **Precedence Invariant:** `@Qualifier` **ALWAYS overrides `@Primary`**.
> - `@Primary` sets a global fallback default.
> - `@Qualifier` represents an explicit, intentional targeting choice at a specific injection point.

```
  Bean A [@Primary] ──────┐
                          ├──> [Consumer with `@Qualifier("beanB")`] ──> Injects Bean B!
  Bean B [@Qualifier] ────┘
```

### Applying `@Qualifier` Across the Architecture

```java
// 1. On Component Classes:
@Component
@Qualifier("fastProcessor")
public class HighThroughputProcessor implements DataProcessor { ... }

// 2. On @Bean Factory Methods:
@Bean
@Qualifier("readOnlyDataSource")
public DataSource readOnlyDataSource() { ... }

// 3. On Constructor Parameter Injection Points:
@Service
public class AnalyticsService {
    public AnalyticsService(@Qualifier("readOnlyDataSource") DataSource ds) { ... }
}
```

## 🔴 Senior Level

### Custom Type-Safe Qualifiers with Attributes

String qualifiers like `@Qualifier("oracleReadOnlyDb")` fail silently until runtime when typos occur. Spring supports **custom qualifier annotations with matching attributes**:

```java
@Target({ElementType.FIELD, ElementType.PARAMETER, ElementType.METHOD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Qualifier // Meta-annotation
public @interface DatabaseType {
    String engine() default "postgres";
    boolean replica() default false;
}
```

```java
// 1. Defining Parameterized Beans:
@Bean
@DatabaseType(engine = "postgres", replica = true)
public DataSource readReplicaPostgres() { ... }

@Bean
@DatabaseType(engine = "postgres", replica = false)
public DataSource primaryPostgres() { ... }

// 2. Injecting Exact Parameterized Bean:
@Service
public class ReportingService {
    // Spring matches ALL annotation attributes during resolution:
    public ReportingService(@DatabaseType(engine = "postgres", replica = true) DataSource ds) {
        this.ds = ds;
    }
}
```

## 🎯 Interview Cheat Sheet

**Must Know:**
- **Definition:** Disambiguation annotation that filters candidate beans by qualifier name or qualifier meta-annotation.
- **Precedence Hierarchy:** `@Qualifier` > `@Primary` > variable name match (`byName`) > `@Priority`.
- **Target Points:** Works on classes (`@Component`), methods (`@Bean`), fields, and constructor/setter parameters.
- **Custom Meta-Annotations:** Create `@interface` meta-annotated with `@Qualifier` for compile-time type safety.
- **Attribute Matching:** Spring matches all attributes declared on custom qualifier annotations.

**Common Follow-up Questions:**
- *"What happens if a `@Qualifier` string does not match any registered bean?"* → Spring throws `NoSuchBeanDefinitionException`.
- *"Can you use Jakarta `@Qualifier` from `jakarta.inject` in Spring Boot 3?"* → Yes. Spring fully supports standard `jakarta.inject.Qualifier` interchangeably with Spring's `org.springframework.beans.factory.annotation.Qualifier`.
- *"How do you inject a specific bean dynamically at runtime based on a configuration key?"* → Inject `Map<String, TargetInterface>` and retrieve the target bean dynamically via `map.get(key)`.

**Red Flags (DO NOT Say):**
- ❌ *"@Primary takes precedence over @Qualifier."* (@Qualifier has the highest precedence).
- ❌ *"@Qualifier only matches bean names."* (It matches qualifier tags, custom annotations, or bean names if no qualifier tag exists).
- ❌ *"Custom qualifier annotations cannot have attribute methods."* (Spring evaluates all attribute key-value pairs during candidate matching).
