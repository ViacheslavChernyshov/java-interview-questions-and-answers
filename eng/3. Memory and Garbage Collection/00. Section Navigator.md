## 🔗 Key Topic Relationships

### JVM Memory Cluster
```
Q1 (Heap vs Stack) ──> Q2 (Stored in Heap) ──> Q3 (Stored in Stack)
         │
         ▼
Q4 (GC Overview) ──> Q5 (Eligibility) ──> Q25 (GC Roots) ──> Q26 (Reachability)
```
- **Q1 ↔ Q25:** Thread stacks contain local variable frames which serve as root pointers (**GC Roots**).
- **Q2 ↔ Q11:** Heap contains object instances; Metaspace resides in native memory holding loaded class metadata.

### Memory Generations Cluster
```
Q8 (Generations) ──> Q9 (Young Gen) ──> Q10 (Old Gen) ──> Q11 (Metaspace)
```
- **Q8 ↔ Q12:** The Weak Generational Hypothesis dictates using Copying algorithms for Young Gen and Compact algorithms for Old Gen.
- **Q9 ↔ Q10:** Objects surviving `-XX:MaxTenuringThreshold` Minor GC cycles are promoted from Survivor to Tenured space.

### Garbage Collector Cluster
```
Q12 (Algorithms) ──> Q13 (G1) ──> Q14 (ZGC) ──> Q15 (Shenandoah)
        │
        ▼
Q16 (Stop-the-World) ──> Q17 (Low-Latency Collectors)
```
- **Q13 ↔ Q14:** G1 provides predictable target pauses (~200ms); ZGC achieves sub-millisecond pauses (<1ms) via colored pointers.
- **Q14 ↔ Q15:** ZGC uses metadata bits inside pointers + load barriers; Shenandoah uses load-reference barriers.

## 🎓 Level-by-Level Knowledge Matrix

### 🟢 Junior
- **Heap** stores all class instances and arrays (shared across threads); **Stack** stores method frames and local variables (thread-isolated).
- The **Garbage Collector** automatically reclaims memory occupied by unreachable objects.
- Generations: Young (Eden, S0, S1), Old (Tenured), Metaspace (Class metadata in native RAM).
- `-Xms` sets initial heap size; `-Xmx` sets maximum heap ceiling.

### 🟡 Middle
- **GC Roots** include active thread stack variables, static class fields, JNI handles, and JVM internal references.
- **G1 GC** divides heap into equal-sized Regions (1MB–32MB) and uses SATB (Snapshot-At-The-Beginning) concurrent marking.
- **ThreadLocal Leaks:** Occur when worker threads in thread pools reuse threads without calling `ThreadLocal.remove()`.
- **Heap Dumps (`.hprof`):** Triggered via `-XX:+HeapDumpOnOutOfMemoryError` or `jcmd <pid> GC.heap_dump`.

### 🔴 Senior
- **ZGC Colored Pointers:** Encodes metadata (Marked0, Marked1, Remapped) directly into the upper bits of 64-bit object references; load barriers intercept references and self-heal them during relocation.
- **Escape Analysis (JIT):** If an object does not escape the allocating method, HotSpot performs **Scalar Replacement**, breaking the object down into primitive registers/stack variables to bypass Heap allocation completely.
- **TLAB (Thread Local Allocation Buffer):** Pre-allocated Eden buffers per thread allowing fast, lock-free bump-the-pointer heap allocations.
- **Eclipse MAT Analysis:** Dominator Tree calculation distinguishes between **Shallow Heap** (memory consumed by the object itself) and **Retained Heap** (memory freed if the object is garbage collected).
