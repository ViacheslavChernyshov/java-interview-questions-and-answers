# What Cascade Types Exist?

---

## 🟢 Junior Level

In JPA, the **`CascadeType`** enum defines the specific lifecycle operations that are automatically propagated from a parent entity to its related child entities:

```
  ┌──────────────────────────────┬─────────────────────────────────────────────────────────────────────────────────┐
  │ CascadeType Enum             │ Propagated EntityManager Operation                                              │
  ├──────────────────────────────┼─────────────────────────────────────────────────────────────────────────────────┤
  │ **`CascadeType.PERSIST`**    │ `em.persist(parent)` automatically persists new child entities.                 │
  │ **`CascadeType.MERGE`**      │ `em.merge(parent)` automatically merges detached child state.                   │
  │ **`CascadeType.REMOVE`**     │ `em.remove(parent)` automatically deletes associated child entities.           │
  │ **`CascadeType.REFRESH`**    │ `em.refresh(parent)` automatically reloads child state from the database.       │
  │ **`CascadeType.DETACH`**     │ `em.detach(parent)` automatically evicts children from the Persistence Context. │
  │ **`CascadeType.ALL`**        │ 🏆 Bundles **ALL 5** operations (`PERSIST`, `MERGE`, `REMOVE`, `REFRESH`, `DETACH`) │
  └──────────────────────────────┴─────────────────────────────────────────────────────────────────────────────────┘
```

```java
// Example: Propagating only PERSIST and MERGE (Safe for shared associations):
@Entity
public class Post {
    @ManyToMany(cascade = {CascadeType.PERSIST, CascadeType.MERGE})
    private List<Tag> tags = new ArrayList<>();
}
```

## 🟡 Middle Level

### Domain-Driven Design (DDD): Composition vs. Association

Selecting the correct `CascadeType` depends entirely on whether the relationship represents a **Composition (Aggregate)** or a **Shared Association**:

```
  ┌──────────────────────────────────────────┬──────────────────────────────────────────────────┐
  │ 📦 COMPOSITION (Aggregate Root)          │ 🔗 SHARED ASSOCIATION (Independent Entities)     │
  ├──────────────────────────────────────────┼──────────────────────────────────────────────────┤
  │ • Child cannot exist without parent.     │ • Entities exist independently with own lifecycles│
  │ • Example: `Order` ➔ `OrderItem`         │ • Example: `Order` ➔ `Customer`, `Post` ➔ `Tag`  │
  │ • Recommended:                           │ • Recommended:                                   │
  │   `cascade = CascadeType.ALL`            │   `cascade = {CascadeType.PERSIST}` or **NONE**  │
  │   `+ orphanRemoval = true`               │   🚨 **NEVER USE `CascadeType.REMOVE` or `ALL`!** │
  └──────────────────────────────────────────┴──────────────────────────────────────────────────┘
```

```java
// 1. COMPOSITION (Cascade ALL + Orphan Removal):
@Entity
public class Order {
    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<OrderItem> items = new ArrayList<>();
}

// 2. SHARED ASSOCIATION (No Cascading or PERSIST only):
@Entity
public class Order {
    @ManyToOne(fetch = FetchType.LAZY) // Zero cascading! Customer is independent!
    @JoinColumn(name = "customer_id")
    private Customer customer;
}
```

## 🔴 Senior Level

### Proprietary Hibernate Cascade Extensions

In addition to standard JPA `CascadeType`, Hibernate provides its own proprietary enum (`org.hibernate.annotations.CascadeType`):

```java
@Entity
public class Account {
    @OneToMany(mappedBy = "account")
    @org.hibernate.annotations.Cascade({
        org.hibernate.annotations.CascadeType.SAVE_UPDATE, // Cascades legacy saveOrUpdate()
        org.hibernate.annotations.CascadeType.LOCK,        // Re-associates detached children on lock()
        org.hibernate.annotations.CascadeType.REPLICATE    // Propagates cross-DB replicate()
    })
    private List<Transaction> transactions;
}
```

### Cascade Type Safety Audit Checklist

```
  ┌──────────────────────┬──────────────────────────────┬──────────────────────────────────────────────────┐
  │ Relationship Mapping │ Permitted Cascade Types      │ Strictly Forbidden Cascade Types                 │
  ├──────────────────────┼──────────────────────────────┼──────────────────────────────────────────────────┤
  │ **`@OneToMany`**     │ `ALL`, `PERSIST`, `MERGE`    │ None (All are safe when owning aggregate).       │
  │ **`@OneToOne`**      │ `ALL` (if owning child)      │ `REMOVE` (if child is shared across entities).   │
  │ **`@ManyToOne`**     │ `PERSIST`, `MERGE` (Rare)    │ 🚨 **`REMOVE`**, **`ALL`** (Deletes parents!).   │
  │ **`@ManyToMany`**    │ `PERSIST`, `MERGE`           │ 🚨 **`REMOVE`**, **`ALL`** (Deletes join targets)│
  └──────────────────────┴──────────────────────────────┴──────────────────────────────────────────────────┘
```

## 🎯 Interview Cheat Sheet

**Must Know:**
- **JPA Types:** `PERSIST`, `MERGE`, `REMOVE`, `REFRESH`, `DETACH`, `ALL`.
- **`CascadeType.ALL`:** Applies all 5 operations simultaneously.
- **Composition Rule:** Use `CascadeType.ALL` only for strict parent-child aggregate roots (`Order ➔ OrderItem`).
- **Association Rule:** Never use `REMOVE` or `ALL` on `@ManyToOne` or `@ManyToMany` mappings.
- **Detached Operations:** `CascadeType.MERGE` ensures child entities are merged when a detached parent is merged.

**Common Follow-up Questions:**
- *"If you call `em.persist(parent)` but have only configured `CascadeType.MERGE`, will the child be saved?"* → No; `CascadeType.MERGE` propagates only during `em.merge()`. Hibernate will throw `TransientPropertyValueException` because the child is unpersisted.
- *"What is the difference between JPA CascadeType and Hibernate CascadeType?"* → JPA's `CascadeType` is vendor-neutral (`jakarta.persistence`); Hibernate's `@Cascade` provides legacy proprietary options (`SAVE_UPDATE`, `LOCK`, `REPLICATE`).
- *"Why is `CascadeType.REMOVE` dangerous on `@ManyToMany`?"* → If Student A and Student B both attend "Math 101", deleting Student A with `CascadeType.REMOVE` will delete the "Math 101" course row itself, corrupting Student B's enrollments!

**Red Flags (DO NOT Say):**
- ❌ *"Always use `CascadeType.ALL` on every JPA relationship."* (Causes catastrophic cascading deletions of shared data).
- ❌ *"`CascadeType.PERSIST` deletes child records when they are removed from a List."* (Deletion on list removal requires `orphanRemoval = true`).
- ❌ *"CascadeType affects database tables directly without Hibernate being running."* (JPA cascades are strictly managed by Hibernate in application memory).
