## 🎯 Structured Learning Tracks

### 🟢 Junior Track (Core Transaction Concepts)
1. Understand the core ACID guarantees: [Explain Each Letter of ACID](01.%20Explain%20Each%20Letter%20of%20ACID.md).
2. Learn the 4 standard SQL isolation levels: [What Transaction Isolation Levels Exist](02.%20What%20Transaction%20Isolation%20Levels%20Exist.md).
3. Understand the basic anomalies: [What is Dirty Read](07.%20What%20is%20Dirty%20Read.md) and [What is Non-Repeatable Read](08.%20What%20is%20Non-Repeatable%20Read.md).
4. Master Spring transaction basics: [What is the Transactional Annotation](16.%20What%20is%20the%20Transactional%20Annotation.md) and [Which Exceptions Trigger Rollback by Default](19.%20Which%20Exceptions%20Trigger%20Rollback%20by%20Default.md).

### 🟡 Middle Track (Isolation Mechanics & Propagation)
1. Contrast MVCC in PostgreSQL vs Next-Key Locking in MySQL: [What is the Default Isolation Level in PostgreSQL](11.%20What%20is%20the%20Default%20Isolation%20Level%20in%20PostgreSQL.md) vs [What is the Default Isolation Level in MySQL](12.%20What%20is%20the%20Default%20Isolation%20Level%20in%20MySQL.md).
2. Prevent concurrency overwrites: [What is Lost Update](10.%20What%20is%20Lost%20Update.md).
3. Master Spring propagation rules: [What is Transaction Propagation in Spring](13.%20What%20is%20Transaction%20Propagation%20in%20Spring.md) and [What is the Difference Between REQUIRED and REQUIRES_NEW](15.%20What%20is%20the%20Difference%20Between%20REQUIRED%20and%20REQUIRES_NEW.md).
4. Configure fine-grained rollbacks: [How to Configure Rollback for Checked Exceptions](20.%20How%20to%20Configure%20Rollback%20for%20Checked%20Exceptions.md) and [What Does Propagation NESTED Do](14.%20What%20Does%20Propagation%20NESTED%20Do.md).

### 🔴 Senior Track (Highload, AOP Proxies & Concurrency Pitfalls)
1. Dive into Serializable Snapshot Isolation (SSI): [What is Serializable](06.%20What%20is%20Serializable.md).
2. Optimize Hibernate/JPA read throughput: [What is a ReadOnly Transaction](21.%20What%20is%20a%20ReadOnly%20Transaction.md).
3. Diagnose and eliminate Spring AOP proxy self-invocation bugs: [What Happens When Calling a Transactional Method from Another Method in the Same Class](22.%20What%20Happens%20When%20Calling%20a%20Transactional%20Method%20from%20Another%20Method%20in%20the%20Same%20Class.md).
4. Prevent connection pool exhaustion when nesting `REQUIRES_NEW` transactions.
