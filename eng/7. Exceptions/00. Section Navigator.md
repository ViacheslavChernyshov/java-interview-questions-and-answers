## 🎯 Recommended Learning Path

### 🟢 Junior Level (Weeks 1–2)
1. **Hierarchy:** [What is at the top of the exception hierarchy](05.%20What%20is%20at%20the%20top%20of%20the%20exception%20hierarchy.md), [What is the difference between Error and Exception](07.%20What%20is%20the%20difference%20between%20Error%20and%20Exception.md).
2. **Checked vs. Unchecked:** [What is the difference between checked and unchecked exceptions](01.%20What%20is%20the%20difference%20between%20checked%20and%20unchecked%20exceptions.md), [Which exceptions must be handled](04.%20Which%20exceptions%20must%20be%20handled.md).
3. **Basic Flow:** [What does the throws keyword do](021.%20What%20does%20the%20throws%20keyword%20do.md), [Can you have multiple catch blocks for one try](25.%20Can%20you%20have%20multiple%20catch%20blocks%20for%20one%20try.md), [In what order should catch blocks be arranged](27.%20In%20what%20order%20should%20catch%20blocks%20be%20arranged.md).
4. **Basic Logging:** [What does the printStackTrace() method do](17.%20What%20does%20the%20printStackTrace()%20method%20do.md).

### 🟡 Middle Level (Weeks 3–4)
1. **Resource Management:** [Is the execution of a finally block guaranteed](08.%20Is%20the%20execution%20of%20a%20finally%20block%20guaranteed.md), [What is try-with-resources](09.%20What%20is%20try-with-resources.md), [What is the AutoCloseable interface](11.%20What%20is%20the%20AutoCloseable%20interface.md), [What is the difference between AutoCloseable and Closeable](12.%20What%20is%20the%20difference%20between%20AutoCloseable%20and%20Closeable.md).
2. **Domain Modeling:** [Can you create custom exceptions](13.%20Can%20you%20create%20custom%20exceptions.md), [When should you create your own exceptions](14.%20When%20should%20you%20create%20your%20own%20exceptions.md), [What is better: extend Exception or RuntimeException](15.%20What%20is%20better%20extend%20Exception%20or%20RuntimeException.md).
3. **Enterprise Handling:** [How to properly log exceptions](18.%20How%20to%20properly%20log%20exceptions.md), [What is exception wrapping](19.%20What%20is%20exception%20wrapping.md), [Why you should not swallow exceptions](20.%20Why%20you%20should%20not%20swallow%20exceptions.md), [What is multi-catch](26.%20What%20is%20multi-catch.md), [What is exception chaining](29.%20What%20is%20exception%20chaining.md).

### 🔴 Senior Level (Weeks 5–6)
1. **JVM Mechanics & Performance:** Stack trace generation cost (`fillInStack()`), creating stackless exceptions for high-frequency control flow.
2. **Compiler Secrets:** Sneaky Throws via generic type erasure (`@SneakyThrows` / `Lombok`), precise rethrow bytecode analysis.
3. **Suppression & Concurrency:** Suppressed exceptions mechanism in Try-With-Resources and Structured Concurrency (`StructuredTaskScope`).
4. **Resilience & Production Fault Tolerance:** Circuit Breaker exception classification, Spring `@ControllerAdvice` + RFC 9457 `ProblemDetail`.
