## 🎓 Quick Revision Invariants

### 🟢 Junior Essentials
- **Internal Array:** `Node<K,V>[] table` backing array where index = `(n - 1) & hash`.
- **Contract Rule:** If `a.equals(b)` is true, `a.hashCode() == b.hashCode()` MUST be true.
- **Collisions:** Same hash code $\ne$ equal objects; collisions are chained in bucket linked lists.
- **Null Handling:** `HashMap` allows exactly one `null` key (mapped to bucket 0) and multiple `null` values; `Hashtable` and `ConcurrentHashMap` forbid `null`.

### 🟡 Middle Essentials
- **Treeification (Java 8+):** When bucket length reaches **8** AND table capacity $\ge$ **64**, the bucket converts from a linked list into a **Red-Black Tree** (`TreeNode`, $O(\log N)$ lookup). If capacity $< 64$, the table resizes instead of treeifying.
- **Untreeify Threshold:** When elements in a treeified bucket drop to **6** during resize or removal, it reverts to a linked list.
- **Load Factor (0.75):** The optimal balance between memory utilization and collision frequency. Threshold = `capacity * 0.75`.
- **Mutable Key Anti-Pattern:** Mutating a key after insertion changes its hash code, making it impossible to locate in its original bucket (memory leak + silent data loss).

### 🔴 Senior Essentials
- **Hash Spread:** `(key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16)` folds higher 16 bits into lower 16 bits to prevent lower-bit clustering.
- **Resize Lo/Hi Split:** Because capacity doubles as a power of two, elements either stay at their current index `i` or move to `i + oldCap` based on a single bit check `(e.hash & oldCap) == 0`.
- **Java 7 vs Java 8 Multi-Threading:** Java 7 Head Insertion during resize caused circular linked lists and 100% CPU infinite loops. Java 8 Tail Insertion eliminates circular loops, but concurrent writes without synchronization still cause silent lost updates and memory corruption.
- **`ConcurrentHashMap` Highload:** Lock-free CAS for empty buckets, fine-grained bucket synchronization for populated heads, and sharded `CounterCell[]` array for high-throughput `size()` calculation.
