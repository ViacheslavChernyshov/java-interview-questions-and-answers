## 🎯 Recommended Learning Paths

### 🟢 Junior Level Track
1. **Basics:** [What is the difference between Thread and Runnable](26.%20What%20is%20the%20difference%20between%20Thread%20and%20Runnable.md), [What are Callable and Future](27.%20What%20are%20Callable%20and%20Future.md).
2. **Synchronization:** [What is the difference between synchronized and volatile](01.%20What%20is%20the%20difference%20between%20synchronized%20and%20volatile.md), [What is visibility problem](03.%20What%20is%20visibility%20problem.md).
3. **Monitors:** [What is monitor in Java](04.%20What%20is%20monitor%20in%20Java.md), [Method vs block synchronization](06.%20What%20is%20the%20difference%20between%20synchronized%20method%20and%20synchronized%20block.md).
4. **Concurrency Traps:** [What is deadlock](17.%20What%20is%20deadlock.md), [What is race condition](20.%20What%20is%20race%20condition.md).

### 🟡 Middle Level Track
1. **JMM & Memory Barriers:** [What is happens-before relationship](02.%20What%20is%20happens-before%20relationship.md).
2. **Advanced Locking:** [How does synchronized work at monitor level](05.%20How%20does%20synchronized%20work%20at%20monitor%20level.md), [What is reentrant lock](07.%20What%20is%20reentrant%20lock.md).
3. **Lock-Free Concurrency:** [What are Atomic classes](08.%20What%20are%20Atomic%20classes.md), [What is CAS (Compare-And-Swap)](09.%20What%20is%20CAS%20(Compare-And-Swap).md), [How do AtomicInteger, AtomicLong work](10.%20How%20do%20AtomicInteger,%20AtomicLong%20work.md).
4. **Executors & Sizing:** [What is Thread Pool](12.%20What%20is%20Thread%20Pool.md), [What types of Thread Pool exist in Java](13.%20What%20types%20of%20Thread%20Pool%20exist%20in%20Java.md), [What does ExecutorService do](14.%20What%20does%20ExecutorService%20do.md), [Fixed vs Cached ThreadPool](15.%20What%20is%20the%20difference%20between%20Executors.newFixedThreadPool()%20and%20newCachedThreadPool().md).
5. **Deadlock Resolution:** [What conditions are necessary for deadlock to occur](18.%20What%20conditions%20are%20necessary%20for%20deadlock%20to%20occur.md), [How to prevent deadlock](19.%20How%20to%20prevent%20deadlock.md), [How to avoid race condition](21.%20How%20to%20avoid%20race%20condition.md).

### 🔴 Senior Level Track
1. **JVM Monitor Evolution:** Thin Lock $\to$ Fat Lock, Mark Word CAS inflation, biased locking deprecation in Java 21 ([Q05](05.%20How%20does%20synchronized%20work%20at%20monitor%20level.md)).
2. **Hardware Lock-Free Realities:** `LOCK CMPXCHG`, MESI cache coherency traffic, Cache Line Bouncing, ABA problem & `AtomicStampedReference` ([Q09](09.%20What%20is%20CAS%20(Compare-And-Swap).md), [Q10](10.%20How%20do%20AtomicInteger,%20AtomicLong%20work.md)).
3. **Virtual Threads Internal Architecture:** Carrier threads, `Continuation` stack chunk unmounting, pinning hazards in `synchronized` blocks vs `ReentrantLock` ([Q22](22.%20What%20are%20Virtual%20Threads%20in%20Java%2021.md), [Q23](23.%20What%20are%20the%20advantages%20of%20Virtual%20Threads%20over%20regular%20threads.md), [Q24](24.%20When%20should%20you%20use%20Virtual%20Threads.md)).
4. **Structured Concurrency:** `StructuredTaskScope`, cancellation propagation, short-circuiting async sub-tasks ([Q25](25.%20What%20is%20structured%20concurrency.md)).
5. **Thread Pool Tuning Formulas:** Sizing CPU-bound ($N_{\text{threads}} = N_{\text{cores}} + 1$) vs I/O-bound ($N_{\text{threads}} = N_{\text{cores}} \times (1 + \frac{W}{C})$), rejection policies, saturation monitoring ([Q12](12.%20What%20is%20Thread%20Pool.md)–[Q16](16.%20What%20is%20ForkJoinPool.md)).
