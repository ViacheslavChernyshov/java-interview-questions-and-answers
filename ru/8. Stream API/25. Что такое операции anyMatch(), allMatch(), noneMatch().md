# Что такое операции anyMatch(), allMatch(), noneMatch()?

---

## 🟢 Junior Level

### Простое определение

Операции **`anyMatch()`**, **`allMatch()`** и **`noneMatch()`** — это **терминальные операции короткого замыкания (short-circuiting)**, которые проверяют соответствие элементов стрима заданному условию (`Predicate<T>`) и возвращают примитивный **`boolean`**:

| Метод | Логический смысл | Когда останавливается (Short-circuit) | Пример |
| :--- | :--- | :--- | :--- |
| **`anyMatch(p)`** | ХОТЯ БЫ ОДИН элемент удовлетворяет условию | На первом элементе, вернувшем **`true`** | Есть ли хоть один совершеннолетний? |
| **`allMatch(p)`** | ВСЕ элементы удовлетворяют условию | На первом элементе, вернувшем **`false`** | Все ли пользователи активны? |
| **`noneMatch(p)`** | НИ ОДИН элемент не удовлетворяет условию | На первом элементе, вернувшем **`true`** | Нет ли заблокированных аккаунтов? |

### Базовый пример:

```java
List<Integer> numbers = List.of(2, 4, 6, 7, 8);

boolean hasOdd = numbers.stream().anyMatch(n -> n % 2 != 0);   // true (нашел 7 и сразу вышел)
boolean allEven = numbers.stream().allMatch(n -> n % 2 == 0); // false (нашел 7 и сразу вышел)
boolean noNegative = numbers.stream().noneMatch(n -> n < 0);   // true (проверил все, отрицательных нет)
```

## 🟡 Middle Level

### Логика работы на пустом стриме: «Пустая истинность» (Vacuous Truth)

Классический каверзный вопрос на собеседованиях: **что вернет каждый метод на пустом стриме (`Stream.empty()`)?**

```java
Stream.empty().anyMatch(x -> true);  // ❌ false
Stream.empty().allMatch(x -> false); // ✅ true! (Да, даже с false-предикатом!)
Stream.empty().noneMatch(x -> true); // ✅ true!
```

#### Математическое обоснование:
1. **`anyMatch` ($\exists x \in S : P(x)$)**: «Существует ли в множестве хотя бы один элемент, удовлетворяющий условию?» В пустом множестве элементов нет $\rightarrow$ **`false`**.
2. **`allMatch` ($\forall x \in S : P(x)$)**: «Все ли элементы удовлетворяют условию?» По законам математической логики утверждение истинно, если не существует ни одного контрпримера, нарушающего правило (**Vacuous Truth**). Контрпримеров нет $\rightarrow$ **`true`**.
3. **`noneMatch` ($\neg \exists x \in S : P(x)$)**: «Правда ли, что ни один элемент не удовлетворяет условию?» Так как элементов нет, ни один ничего не нарушил $\rightarrow$ **`true`**.

## 🔴 Senior Level

### Внутреннее устройство: `MatchOp` и `ShortCircuitTask` в `ForkJoinPool`

Под капотом все три метода используют общий внутренний класс **`MatchOps`**:

```java
enum MatchKind {
    ANY(true, true),      // останавливается при true, начальное значение false
    ALL(false, false),    // останавливается при false, начальное значение true
    NONE(true, false);    // останавливается при true, начальное значение true

    final boolean stopOnPredicateMatches;
    final boolean shortCircuitResult;
}
```

#### Поведение в `parallelStream()`:
1. Задачи разбиваются по потокам пула через **`MatchTask`** (наследник `ForkJoinTask`).
2. Как только один из потоков находит замыкающее условие (например, `false` для `allMatch`), он атомарно устанавливает флаг отмены `shortCircuit = true` в общем `SharedResult`.
3. Все остальные потоки пула получают сигнал прерывания вычислений и сбрасывают свои локальные задачи.

### Работа с бесконечными стримами (Infinite Streams)

- **`Stream.generate(...).anyMatch(predicate)`**: Безопасно завершится и вернет `true`, как только генератор выдаст первый подходящий элемент.
- **`Stream.generate(...).allMatch(predicate)`**: Если предикат всегда возвращает `true`, стрим **зависнет в бесконечном цикле (100% CPU)**, потому что алгоритм безуспешно будет искать первый контрпример `false`.

## 🎯 Шпаргалка для интервью

**Обязательно знать:**
- `anyMatch`, `allMatch`, `noneMatch` — терминальные операции короткого замыкания, возвращающие `boolean`.
- `anyMatch` останавливается на первом `true`; `allMatch` останавливается на первом `false`; `noneMatch` останавливается на первом `true`.
- **Поведение на пустом стриме (`Stream.empty()`):**
  - `anyMatch()` $\rightarrow$ `false`
  - `allMatch()` $\rightarrow$ `true` (Vacuous Truth)
  - `noneMatch()` $\rightarrow$ `true`
- Не создают промежуточных объектов `Optional` или коллекций — максимально эффективны по памяти ($O(1)$).
- В бесконечных стримах `allMatch(x -> true)` зависнет навсегда.

**Частые уточняющие вопросы:**
- **Почему allMatch на пустом стриме возвращает true?** — По законам математической логики (Vacuous Truth): в пустом множестве отсутствуют контрпримеры, опровергающие утверждение.
- **В чём разница между `stream.filter(p).findFirst().isPresent()` и `stream.anyMatch(p)`?** — `anyMatch` не создает объект `Optional<T>` в куче и выполняется быстрее.
- **Работает ли short-circuiting в параллельном режиме?** — Да, при нахождении нужного элемента поток выставляет флаг отмены в `MatchTask`, прерывая соседние потоки ForkJoinPool.

**Красные флаги (НЕ говорить):**
- ❌ «`allMatch()` на пустом стриме всегда вернет `false`».
- ❌ «`allMatch()` обязан проверить абсолютно все элементы до единого, даже если первый же элемент вернул `false`».
- ❌ «Операции match возвращают найденный элемент стрима».
