Полная коллекция из **500+ вопросов для собеседований** по всем ключевым темам для Java Backend разработчиков уровней Junior, Middle и Senior. Каждый вопрос включает ответ, структурированный по трём уровням глубины: 🟢 Junior, 🟡 Middle и 🔴 Senior.

## Структура ответов

Каждый ответ следует единому формату:

- **🟢 Junior Level** — Простые определения, базовые концепции, понятные аналогии и примеры
- **🟡 Middle Level** — Внутреннее устройство, практическое применение, частые ошибки, trade-offs
- **🔴 Senior Level** — Глубокие детали реализации, архитектурные решения, edge cases, бенчмарки, production-сценарии

## Для кого этот репозиторий

- Java Backend разработчиков, готовящихся к собеседованиям на уровне Junior, Middle или Senior
- Инженеров, которым нужно быстро повторить Spring Boot, SQL, Kafka, многопоточность или JVM internals
